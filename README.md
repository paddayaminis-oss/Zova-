# 🛍️ Zova - Full-Stack Product Catalog & E-Commerce Web Application

Zova is a modern, responsive e-commerce web application and product catalog designed to deliver a seamless online shopping experience. Featuring an intuitive user interface, interactive navigation, and dedicated category hubs, Zova replicates the feel of a full-scale digital marketplace.

---

## ✨ Key Features

* **Dynamic Navigation & Layout:** A responsive top navigation bar coupled with a sliding category sidebar for effortless browsing.
* **Diverse Product Categories:** Dedicated sections and pages for:
  * 🥦 **Fresh Groceries**
  * 💳 **Zova Pay** (Integrated digital payment/services hub)
  * 📱 **Mobiles & Electronics**
  * 👗 **Dresses & Fashion**
  * ⚡ **Today's Deals & Special Offers**
* **Customer Support Hub:** Built-in customer service pages to assist users with inquiries.
* **Modern UI/UX:** Styled using Bootstrap, HTML5, and CSS3 to ensure responsiveness across desktop, tablet, and mobile devices.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
* **Architecture:** Component-based layout structure with dynamic sidebar interactions
* **Version Control:** Git & GitHub
